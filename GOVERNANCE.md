# Governance

## Core Team (Merge Rights)

| Name | Role |
|---|---|
| **Ant Newman** | Editorial lead, founding author |
| **Shanti Greene** | Editorial lead, co-author |
| **Malia Hosseini** | Technical reviewer — gatekeeper role: rejects non-conformant contributions with reasons |

---

## Decision-Making

- All three core team members must approve any merge from `dev` into `main`
- Any one of the three can approve a merge from `feat` into `dev`, but the other two must be notified
- No force pushes to `dev` or `main` under any circumstances

---

## Response Times

Pull requests will be reviewed within five working days. If a reviewer cannot meet that timeline, they comment on the pull request to set expectations.

---

## Future Governance

As the project grows, the core team may expand. Governance is transparent, democratic, and not controlled by any single person. This repository is initially hosted on Ant Newman's personal GitHub account with the explicit intent to transfer ownership to a neutral third-party organisation as community adoption warrants it.
