# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for key design choices in the Verified Autonomy project.

ADRs document the context, decision, and consequences of significant technical and architectural choices. They give expert readers the "why not the alternative" context that separates a reference from a tutorial.

## Format

Each ADR follows the template in [template.md](template.md).
