# Verified Autonomy — Website

> **Status:** Phase two — placeholder scaffold

The field guide will be hosted at [verified-autonomy.netlify.app](https://verified-autonomy.netlify.app) as a static site built from the same markdown content in this repository.

## Architecture

- GitHub repo is the source of truth — markdown, code, and contributions live here
- Netlify builds and hosts the static site from the repo content
- The site is the front door for Substack readers and video viewers
- The repo is the engine room for contributors and practitioners

## Planned Features

- Rendered field guide with navigation across all nine layers
- Embedded companion videos per layer (phase two)
- Interactive code examples
- Search across all nine layers

## Technology

To be decided. Candidates: Astro, Eleventy, or a similar lightweight static site generator with first-class markdown support.
